# VDM10 Intercom — Home Assistant Integration

**Domain:** `vdm10` | **Project:** `vdm10-ha` | **Status:** early development

A Home Assistant custom integration for the Metzler/Hikvision VDM10 door intercom
system. It consumes the [`metzler-vdm10`](https://github.com/lodzen/metzler-vdm)
library in-process and exposes:

- **`binary_sensor.*_doorbell_ringing`** — on exactly while the doorbell is ringing,
  plus `vdm10_ring` / `vdm10_answered` / `vdm10_call_ended` bus events for automations
- **`camera.*_door`** — live door-station video (pull-on-demand only; no stream is
  held open while the entity is unviewed)
- **Two-way audio** — native HA camera talk control during an answered call;
  microphone muted by default on every session
- **`button.*_answer_call` / `button.*_hangup`** — explicit answer control; watching
  the camera never steals the ring from physical indoor stations

## Requirements

- Home Assistant **≥ 2026.11** (native two-way audio capability)
- Standalone **go2rtc add-on** (not the Core-bundled one) for WebRTC + talkback,
  configured per the stream contract (RTSP video + ISAPI audio backchannel)
- Two-way audio preview enabled in HA Labs; HA opened over **HTTPS**
- VDM10 door station + main indoor (registrar) reachable on the LAN

## Installation

1. Settings → Add-ons → install and configure the standalone go2rtc add-on.
2. In Home Assistant, open the **Marketplace → Add from link** and paste this
   repository's URL.
3. Add the integration under Settings → Devices & services → `VDM10 Intercom`
   and enter the registrar address, extension, credentials, and door host.

## Development

```bash
uv sync   # dev deps: homeassistant, pytest-homeassistant-custom-component, ruff, ty
```

The integration ships with the `metzler` library vendored under
`custom_components/vdm10/vendor/` (generated by `tools/vendor.py`); during
development it is consumed as a uv path dependency on the sibling `metzler-vdm10`
project, which continues to run standalone.
